YK OTOMASYON - KOMPLE WEB SITESI PAKETI
======================================

GitHub Pages kurulumu:
1) ZIP dosyasini bilgisayariniza cikarin.
2) index.html, blog.html, akademi.html, logo, resimler ve mp4 dosyasini GitHub web sitesi deposunun ANA KLASORUNE (root) yukleyin.
3) Mevcut index.html ve blog.html dosyalarini bu surumlerle degistirin.
4) GitHub Pages ayarlarinda yayin kaynagini kontrol edin.
5) www.ykotomasyon.com.tr, /blog.html ve /akademi.html adreslerini test edin.

Sayfalar:
index.html  : Ana sayfa
blog.html   : Teknik blog ve PLC secimi makalesi
akademi.html: Ogrenci akademisi, forum tanitimi ve kurumsal egitim

ONEMLI:
- Bu paket mevcut konusmada elde bulunan web sitesi dosyalarini kapsar.
- Ogrenci kayit/giris, gercek forum ve mesaj saklama altyapisi HENUZ KURULU DEGIL.
- Kurumsal egitim talepleri mevcut iletisim bolumune yonlendirilir.
- Var olan GitHub deposunda burada bulunmayan baska dosyalar varsa SILMEYIN.
- Siteyi canliya alma islemi bu paketle otomatik yapilmaz.
