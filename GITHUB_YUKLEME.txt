TURKO STUDIO · GITHUB PAGES GÜNCELLEMESİ

1. ZIP dosyasını çıkarın.
2. Mevcut sitenizin GitHub deposunda main dalının köküne turko-studio.html
   dosyasını yükleyin. Var olan aynı adlı dosyayı güncelleyin.
3. Commit changes ile kaydedin. Actions altında Pages dağıtımı tamamlanınca
   TURKO portalındaki Studio bağlantısını açın.

Pivot Sulama demosu
Yeni Proje > Başlangıç > Pivot Sulama — düzenlenebilir örnek > Oluştur.
Çalışan PLC dili ST iken Simülasyon'a basın ve HMI / Tasarım'ı açın.
Ana ekran, Sektörler ve Alarm ve I/O sayfaları projede yer alır.

PLC / Ladder sekmesinde iki örnek ağ bulunur. Kontak, bobin ve fonksiyon
bloklarını paletten sürükleyin veya seçip uygun + noktasına tıklayın.
Pivot'un enkoder, sektör ve alarm simülasyonu ST ile çalışır.
